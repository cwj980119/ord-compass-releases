# ORD Compass

Windows용 원랜디 보유 유닛 카운터·조합 도우미입니다. 이 저장소에는 설치 및 업데이트 파일만 배포합니다.

## 다운로드 및 설치

[최신 설치 파일 받기](https://github.com/cwj980119/ord-compass-releases/releases/latest)

1. Releases에서 이름이 ORD-Compass-Setup-버전-x64.exe인 설치 파일을 받습니다.
2. Windows 10/11 64비트에서 설치합니다. 설치 경로를 선택할 수 있습니다.
3. 바탕화면 또는 시작 메뉴의 ORD Compass를 실행하고 관리자 권한 확인을 승인합니다.

처음 설치할 때는 EXE 파일 하나만 있으면 됩니다. 별도 Node.js 설치는 필요 없습니다. 현재 Windows 게시자 코드서명 인증서는 적용되지 않았습니다.

## 업데이트

v0.13 이상은 실행 후 새 버전을 확인하고 다운로드합니다. 오른쪽 위 ↻ 버튼에서 진행률과 변경사항을 보고 '업데이트 후 재시작'을 선택하면 설치됩니다. 게임 중에는 나중에 설치해도 됩니다. 업데이트 파일은 앱 내부의 공개키로 서명과 무결성을 확인합니다.

v0.12 이하 사용자는 위 설치 파일로 한 번 설치해야 이후 앱 내 업데이트를 사용할 수 있습니다. 기존 보유패와 목표 설정은 유지됩니다.

## 지원 대상

Warcraft III 1.28.5.7680 및 ORDR 2.323[C] 카탈로그를 대상으로 합니다. 실행 중인 게임을 자동으로 찾으며 다른 엔진 버전과 맵은 지원하지 않습니다.
